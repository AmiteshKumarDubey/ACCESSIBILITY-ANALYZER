Detailed End-to-End Data Flow:

  1. User enters target URL in React Frontend → sends POST /api/audit request to Express Server.
  2. Backend uses Axios to fetch raw HTML with a 20-second timeout and browser User-Agent header.
  3. Cheerio parses HTML into a fast server-side DOM ($).
  4. runWCAGChecks($) & runSEOChecks($) execute 18+ rule checks concurrently.
  5. calculateScore() calculates penalties based on issue severities (Critical: 20, Major: 10, Moderate: 4, Minor: 1).
  6. Overall Score is computed: (WCAG Score × 0.7) + (SEO Score × 0.3).
  7. Suggestion Engine requests Hugging Face / OpenAI API; if unavailable, seamlessly returns local rule suggestions.
  8. Structured JSON response is sent to Frontend for interactive visualization.

3. 📜 WCAG 2.2 Principles & Code Checks Implementation

WCAG 2.2 is structured around four core principles (POUR):

  • Perceivable: Users must be able to see or hear content (Alt text, contrast, viewport).
  • Operable: Users must be able to navigate via keyboard (Focus visible, skip links, clickable controls).
  • Understandable: Clear page structure (Language tag, sequential headings, form labels).
  • Robust: Accessible names for screen readers (ARIA attributes, semantic HTML tags).

Code Logic of Key Checks:

A. Image Alt Text Check (WCAG 1.1.1)
Traverses every <img> tag and checks if alt attribute is missing or empty. Reports first 5 instances with code location to prevent memory bloat. 
$('img').each((i, el) => {
  const alt = $(el).attr('alt');
  if (typeof alt === 'undefined' || alt === null || String(alt).trim() === '') {
    // Push missing-alt issue with element snippet
  }
});
B. Form Input Labels (WCAG 1.3.1 & 4.1.2)
For each form control (input, textarea, select), verifies if a matching <label for="id">, aria-label, or aria-labelledby exists. 
$('input[id], textarea[id], select[id]').each((i, el) => {
  const inputId = $(el).attr('id');
  const label = $(`label[for="${inputId}"]`);
  const ariaLabel = $(el).attr('aria-label');
  if (label.length === 0 && !ariaLabel && !$(el).attr('aria-labelledby')) {
    // Flag unlabelled form input issue
  }
});
C. Heading Hierarchy Check (WCAG 1.3.1)
Inspects sequential heading levels (h1 through h6). Flags broken outline if a heading level skips by more than 1 (e.g., <h1> followed directly by <h3>). 
const headings = $('h1, h2, h3, h4, h5, h6');
let lastLevel = 0;
headings.each((i, el) => {
  const level = parseInt(el.name[1]);
  if (level > lastLevel + 1) hasHeadingSkip = true;
  lastLevel = level;
});

4. 🧮 Scoring System & Formula

The engine uses a weighted penalty classification system:

Severity Level Penalty Points Impact Description & Examples
Critical 20 pts each Completely blocks disabled users (Missing lang, missing <title>, missing viewport, low contrast).
Major 10 pts each Significant usability barrier (Missing image alt, missing form labels, missing/multiple <h1>).
Moderate 4 pts each UX & SEO degradation (Generic link text like "click here", missing focus indicators).
Minor 1 pt each Optimization opportunity (Overuse of generic container <div> tags).
Mathematical Scoring Formula:
• Base Penalty = (Critical × 20) + (Major × 10) + (Moderate × 4) + (Minor × 1)
• Capped Penalty = Min(100, Base Penalty)
• Category Score = 100 - Capped Penalty
• Overall Score = Round( (WCAG Score × 0.7) + (SEO Score × 0.3) )

7. 🎯 Interviewer Rapid-Fire Q&A

Q1: Why did you choose Cheerio over Puppeteer?
Cheerio executes in milliseconds with minimal CPU/RAM overhead because it parses HTML strings without rendering layout or executing JS. Puppeteer takes 3-5 seconds per request and requires high memory. Cheerio is ideal for fast static DOM audits.
Q2: How does your tool handle Client-Side Rendered (CSR) SPAs?
Currently, static HTML parsing gets the initial server response. For SPAs where content mounts dynamically via JS, raw HTML parsing has limitations. As part of future scope, integrating Puppeteer as an optional rendered-DOM parser solves this.
Q3: How do you ensure your score never becomes negative?
By capping the total penalty at 100 using Math.min(100, basePenalty) and enforcing lower bounds with Math.max(0, 100 - cappedPenalty).
